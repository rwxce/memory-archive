    **src/parse/types.ts** — define `export type MessageType = 'text'|'photo'|'video'|'sticker'|'document'|'system'|'deleted'|'omitted';` and `export interface Message { timestamp_iso: string; type: MessageType; author: string; text: string; media: string; }` (D-14, D-15, D-18).

    **src/extract.ts** — `extractChatTxt(zipPath: string): Promise<readline.Interface>` exactly per RESEARCH §1: `new Unzip()`, `unzip.register(AsyncUnzipInflate)`, in `unzip.onfile` compute `base = name.split('/').pop() ?? ''`; skip when `name.includes('__MACOSX') || base.startsWith('._') || !base.endsWith('_chat.txt')` (PARSE-06 — never `file.start()` skipped entries); otherwise pipe `file.ondata` Uint8Array chunks into a `PassThrough` and `readline.createInterface({ input: pass, crlfDelay: Infinity })`, resolve the interface. Also export `chatNameFromZip(zipPath)` that opens the zip, reads entry names, and returns the top-level folder of the `_chat.txt` entry (e.g. `WhatsApp Chat - Plataforma WK`) sanitized for a safe directory name (strip `/` and `..`).

    **src/parse/timestamp.ts** — `stripInvisible(s)` removing a leading run of U+FEFF/U+200E/U+200F/U+200B/U+200C/U+200D/U+2066–U+2069 (D-12). `TS_RE = /^\\[?(\d{1,2})[./-](\d{1,2})[./-](\d{2,4}),?\s(\d{1,2}):(\d{2})(?::(\d{2}))?\s?(am|pm|AM|PM)?\]?/` (D-03 — both iOS `[..]` and Android `..` styles, optional seconds, optional brackets; 12h group captured but treated as 24h in this tracer). `parseTimestamp(stripped, opts)` returns `{ day, month, year, hour, min, sec, iso } | null`. For 2-digit year (D-05): `yy <= (curYear-2000+1) ? 2000+yy : 1900+yy`. Build a LOCAL `Date(year, month-1, day, hour, min, sec)` and produce `iso = format(d, "yyyy-MM-dd'T'HH:mm:ss")` with date-fns (D-06, D-18 — never `toISOString()`). For the tracer, when day/month are both ≤12 (ambiguous), default to DAY-FIRST (pt-BR); full majority-vote detection comes in plan 02.

    **src/parse/message.ts** — `parseMessages(rl: readline.Interface, opts): AsyncGenerator<Message>` implementing the RESEARCH § state machine:
    - `stripInvisible(line)`; if `!TS_RE.test` → append to `current.text` (joined with `\\n`) and continue (PARSE-04, D-10 — preamble/continuation).
    - On match: derive `author`/`body` via `SENDER_RE = /^(?:\s*-\s*)?(.+?):\s([\s\S]*)$/`; if no match → `type='system'`, `author=''`, `body=remainder` (D-11). Preserve `author` RAW (incl. `~ ` prefix, phone bidi wrappers — do NOT strip invisibles inside author/text, D-09, PARSE-05).
    - If `body` matches `<attached:\s*(.+?)>` → set `media = filename`, strip marker from `text`, classify `type` from filename prefix: `STICKER`→sticker, `PHOTO`/`IMG`→photo, `VIDEO`→video, `DOCUMENT`/`.pdf`/`.doc*`/unknown→document, `AUDIO`→document (assumption A1); else `type='text'`.
    - **Empty-body→attachment merge (research §3.4 gotcha):** if a timestamped message has empty `text` and no media, HOLD it in `heldEmpty`; if the very next line is a same-author `<attached>` line, attach media to `heldEmpty` and emit a single media row (no phantom). If next line is not an attachment, emit the empty message as `type=text`.
    - **Same-second burst:** each `<attached>` line is its own row (dedupe key includes media, so not collapsed).

    **src/csv.ts** — `csvField(s)` RFC-4180 quoting when `/[",\n\r]/` present (double inner quotes); `csvRow(m) = [timestamp_iso,type,author,text,media].map(csvField).join(',')+'\n'`; `writeCsv(path, messages)` writes header `timestamp_iso,type,author,text,media\n` then rows via `createWriteStream(path,{encoding:'utf8'})` (Node utf8 adds NO BOM — D-19).

    **src/model.ts** — `runParser(zipPath, { out, dayFirst, monthFirst, verbose })`: derive `chat = chatNameFromZip(zipPath)`, `dir = path.join(out ?? 'out', chat)`, ensure dir, `rl = await extractChatTxt(zipPath)`, collect `messages = []` from `parseMessages(rl, opts)`, `writeCsv(path.join(dir,'messages.csv'), messages)`, return count.

    **src/index.ts** — commander per RESEARCH §6: `.argument('<zip>')`, `.option('--out <dir>')`, `.option('--day-first')`, `.option('--month-first')`, `.option('--verbose')`; action calls `runParser`. (Full verbose reporting added in plan 02; for now accept the flags.)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem→CLI | Untrusted local ZIP (user-supplied) is read and a CSV is written to disk |
| chat content→CSV | Untrusted text/URLs/filenames are stored verbatim |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | fflate ZIP extraction | medium | mitigate | Only `_chat.txt` entry is `file.start()`-ed; media/ZIP-slip entries are never inflated or written → no zip-slip write. `chatNameFromZip` sanitizes the folder name (strip `/` and `..`). |
| T-01-02 | Spoofing/Injection | CSV content (formula injection) | low | accept | Cells starting with `=`,`+`,`-`,`@` could be interpreted by Excel. Output is a personal local backup opened in a browser, not a spreadsheet; documented as accepted-risk. Revisit if a `--spreadsheet-safe` flag is later requested. |
| T-01-03 | Denial of Service | Oversized `_chat.txt` (zip bomb) | medium | mitigate | Streaming readline + PassThrough keeps only current line in memory; `_chat.txt` is inflated entry-by-entry, never the whole archive (PARSE-02). No finite bound needed for v1. |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | fflate/date-fns/commander verified in RESEARCH § Package Legitimacy Audit (OK/Approved); install only these three + dev tooling. Blocking human checkpoint NOT required (all OK). |
| T-01-04 | ReDoS | timestamp `TS_RE` | low | mitigate | Anchored `^`, no nested quantifiers, fixed alternation → linear time. No catastrophic backtracking. |
</threat_model>
