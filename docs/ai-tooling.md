# AI tooling

All AI coding-agent configuration in this repo (Claude Code, Codex CLI, Cursor, OpenCode) is
generated by [rulesync](https://github.com/dyoshikawa/rulesync) (pinned at 33.0.0) from a
single source: `.rulesync/` plus `rulesync.jsonc`.

## What is in `.rulesync/`

| Path | What it is |
|---|---|
| `rules/CLAUDE.md` | Root rule: project context, language, git, review policy, privacy, supply chain, commands, agent routing. Becomes `CLAUDE.md`, `AGENTS.md`, `.cursor/rules/CLAUDE.mdc`. |
| `subagents/` | `core-architect` (data layer), `testing-expert`, `responsive-ui-designer`. |
| `commands/` | PR workflow: `/pr-plan` → `/pr-precheck` → `/pr-make` → `/pr-review` → `/pr-triage`. |
| `skills/` | `debugging`, `interview-me` (adapted from addyosmani/agent-skills, MIT), `pr-scope`, `pr-review`, `security-audit` (Cloudflare, MIT), `rulesync` (v33 reference docs). |
| `hooks.jsonc` | PreToolUse (Bash, fail-closed): `scripts/block-agent-github-review-writes.mjs` stops agents from posting GitHub comments/reviews. Stop (advisory): lint and `scripts/check-pr-preflight.mjs --advisory`. SessionEnd: kills dev processes on the Conductor workspace's ports. |
| `permissions.jsonc` | Read-only `gh` allowed; `gh` comment/review/merge and mutating `gh api` denied; `.env*`, secrets, build output and private data folders read-denied. A `codexcli` block restates the bash rules in a form Codex can enforce. |
| `mcp.jsonc` | Playwright only (pinned), for checking the HTML viewer and later the PWA. |
| `.aiignore` | Legacy ignore list (deprecated upstream); generates `.cursorignore`. |
| `checks/memory-archive-review.md` | Project review checklist; generates `.cursor/BUGBOT.md` and is used by `/pr-precheck` and `/pr-review`. |

## Generated files — never hand-edit

`AGENTS.md`, `CLAUDE.md`, `.claude/`, `.codex/`, `.cursor/`, `.cursorignore`, `.opencode/`,
`.agents/`, `.mcp.json` and `opencode.jsonc` are outputs. They are committed so every tool
works right after clone, but any manual edit is overwritten on the next generate and fails
CI. Edit `.rulesync/` instead.

Exceptions (hand-maintained, not generated): `.claude/agent-memory/` and
`.claude/settings.local.json`. `rulesync.jsonc` keeps `"delete": false` so they survive.

## Regenerate

```bash
pnpm rulesync          # rulesync generate
pnpm rulesync:check    # rulesync generate --check — exits 1 if outputs are stale (runs in CI)
```

Commit the `.rulesync/` change together with the regenerated files.

## Add a skill

1. Create `.rulesync/skills/<name>/SKILL.md`:

   ```md
   ---
   name: <name>
   description: >-
     What it does and when an agent should use it.
   targets: ["*"]
   ---

   # <Title>
   ...
   ```

2. Put supporting files (references, scripts, `LICENSE` for vendored skills) next to it.
   Write everything in English and keep upstream attribution.
3. Run `pnpm rulesync`, then `pnpm rulesync:check` and `pnpm check`.
4. Mention it in the skills line of `.rulesync/rules/CLAUDE.md` if agents should know it exists.

Format reference: the `rulesync` skill, or `pnpm exec rulesync docs reference/file-formats`.

## Known limits (rulesync 33)

- Claude Code and Codex only block on exit code 2; `failClosed` is honored by Cursor only.
- OpenCode has no `sessionEnd` hook, and its generated plugin does not pass the tool payload
  to hook scripts, so the review-write guard is enforced there by `permissions` denies only.
- Codex commands are global-only upstream, so slash commands are not generated for Codex.
- `ajv` (8.20.0) is a direct devDependency only so pnpm links it as the optional peer of
  `ajv-formats` inside rulesync's tree; without it `rulesync` crashes with
  `Cannot find module 'ajv/dist/compile/codegen'`. Remove it once upstream fixes the peer.
- `tldjs` (transitive, via rulesync's MCP server deps) has its install script denied in
  `pnpm-workspace.yaml` `allowBuilds`; it only refreshes a TLD list from the network.
